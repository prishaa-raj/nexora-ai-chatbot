# NOTE: these are minimum-version ranges, not exact pins, on purpose.
# LangChain's sub-packages (core/text-splitters/google-genai/openai/groq)
# release independently and each requires a minimum langchain-core version
# that creeps up over time. Exact-pinning langchain-core while adding a new
# provider package (e.g. langchain-groq) WILL eventually produce a
# ResolutionImpossible error, because the new package needs a newer
# langchain-core than the old exact pin allows. Ranges let pip's resolver
# pick one mutually-compatible set instead of you having to hand-solve the
# version matrix yourself.
langchain-core>=0.3.33,<0.4.0
langchain-text-splitters>=0.3.5,<0.4.0
langchain-google-genai>=2.0.7,<3.0.0
